# Solo Founder Decision Playbook (Condensed)

## The one filter
If it does not improve activation, retention, or revenue in the near term, defer it.

## Decision sequence
1. Is a live user blocked? Fix now.
2. Does this improve first-value in first 24 hours? Prioritize.
3. Does this improve conversion to paid usage? Prioritize.
4. Is this mostly aesthetic or speculative? Defer.

## Weekly reset
- What is the single most important result this week?
- What was built recently that users did not use?
- What user-facing breakage exists right now?

## Unsticking protocol
1. Dump all tasks.
2. Circle one task that most reduces tomorrow's risk.
3. Break into first 15-minute action.
4. Ship, verify, commit.

## Revenue-first framing
- A working onboarding flow beats a new feature.
- One paying centre is higher value than ten incomplete experiments.
