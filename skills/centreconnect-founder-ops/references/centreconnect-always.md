# CentreConnect Always Context (Condensed)

## Business reality
- Solo founder, no team, no funding.
- Time must be protected for high-impact work only.
- Core question: does this action move a real ECD centre closer to paid use?

## Product model
- Parent portal: discovery + applications
- ECD portal: operations + onboarding + retention
- Admin portal: tenant operations and growth controls

## Market constraints
- South African township-first use case
- Budget Android devices, data-sensitive usage
- WhatsApp is the trust channel
- POPIA and child-data privacy expectations

## Priority order
1. Fix blockers in active journeys
2. Improve onboarding completion and first value
3. Increase paid conversion velocity
4. Defer cosmetic or speculative work

## UX rules
- Mobile first
- Keep copy simple and warm
- Reduce clicks and choices
- Keep CTA hierarchy obvious
