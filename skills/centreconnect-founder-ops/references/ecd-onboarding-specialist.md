# ECD Onboarding Specialist (Condensed)

## Trust realities
ECD owners fear:
- breaking something
- hidden costs
- no support when stuck
- staff not adopting

What builds trust:
- personal communication using first name
- one small success quickly
- WhatsApp support availability
- clear, simple steps

## Onboarding target
Drive first-value within 24 hours:
- first login completed
- at least one real operational action taken
  - add children
  - record attendance
  - process first application

## Message style
- warm and direct
- no SaaS jargon
- short sentences
- practical actions

## Lifecycle nudges
- Day 0: invite + clear next step
- Day 1: first-value check-in
- Day 3: friction-removal message
- Day 7: retention check
- Day 14: conversion conversation

## Quality checks for onboarding copy
- Is CTA order obvious?
- Does each CTA map to one clear outcome?
- Is copy short enough for mobile email clients?
- Is support channel visible and human?
