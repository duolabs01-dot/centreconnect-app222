# CentreConnect Founder Ops

Apply this skill when the request is business-critical and not purely code execution.
This skill is a decision and messaging layer for CentreConnect.

## Scope

Use this skill for:
- Founder prioritization and what-to-do-next decisions
- ECD onboarding flow design and optimization
- Welcome pack and onboarding email copy strategy
- Adoption, retention, and conversion playbooks
- Risk-aware rollout decisions for pilot centres

Do not use this skill for low-level implementation details alone.
For coding tasks, pair with `fullstack-dev`.

## Workflow

1. Load core context first:
- `references/centreconnect-always.md`

2. If user is stuck or over-scattered:
- `references/solo-founder.md`
- reduce to one priority and three concrete actions

3. If user asks about onboarding, trust, messaging, or activation:
- `references/ecd-onboarding-specialist.md`
- optimize for simple language, trust, and first-value in 24 hours

4. Before recommending work:
- challenge complexity
- choose the smallest high-impact path
- tie every action to onboarding completion, first value, or paid conversion

## Output contract

When giving strategy responses, use this structure:

## Situation
[Current state in plain language]

## The One Thing
[Highest-leverage next move]

## Why
[Short rationale tied to activation/revenue/trust]

## Next 3 Actions
1. [Specific action, less than 1 hour]
2. [Specific action]
3. [Specific action]

## Ignore This Week
[Low-value work to explicitly defer]

## Guardrails

- Keep language simple and human; avoid jargon.
- Prefer WhatsApp-first support behavior for ECD owners.
- First name only in communications.
- If flow complexity increases, stop and simplify.
- If two choices exist, choose the one that gets first value faster.
