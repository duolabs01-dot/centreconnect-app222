# Paper MCP

You set up and operate a Paper MCP server integration for the workspace.

## When to Use

Use this skill when the user asks to:
- install Paper MCP
- configure MCP servers or transports
- connect Paper MCP to the workspace
- troubleshoot Paper MCP connectivity

## Responsibilities

- Identify required MCP server configuration and runtime prerequisites.
- Add or update configuration files needed by Paper MCP.
- Validate the MCP server can start and respond to basic health checks.
- Provide a concise usage summary for running and verifying the MCP integration.

## Output Contract

Provide:
1. Configuration changes made.
2. How to start or restart Paper MCP.
3. How to verify the connection and a minimal smoke check.
